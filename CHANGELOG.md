# Changelog

All notable changes to Sentinel AI are documented in this file.

The format is based on [Keep a Changelog](https://keepachangelog.com/en/1.1.0/),
and this project adheres to [Semantic Versioning](https://semver.org/spec/v2.0.0.html).

## [1.0.0] - 2026-07-27

### Added

- Apache-2.0 license
- Auth API key scopes (`ingest`, `read`, `write`, `admin`)
- Default/strict payload redaction on ingest and run detail reads
- Ops docs for backup/restore and release process
- CONTRIBUTING and SECURITY policies
- Regression/CI gates, benchmarking, evaluation, adapters (prior phases)

### Changed

- Server versioned as `1.0.0` for first public release line
- ADR-0005 license decision accepted (Apache-2.0)
